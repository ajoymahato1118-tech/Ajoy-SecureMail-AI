# Ajoy SecureMail AI | Advanced Threat Defense Resource

A professional-grade, API-driven Email Spam Detection system built for real-time security auditing. This resource utilizes Natural Language Processing (NLP) with TF-IDF vectorization to identify malicious linguistic patterns.

## 🚀 Key Features
* **TF-IDF Intelligence Engine**: Trained on 5,500+ records for industry-standard accuracy.
* **RESTful API Architecture**: Designed as a searchable resource that other systems can "install" and integrate.
* **Confidence Scoring**: Provides real-time probability metrics for every security scan.
* **Modern UI**: A professional administrative dashboard built with Bootstrap 5.

## 🛠️ Technical Stack
* **Engine**: Python 3.14 (Scikit-Learn)
* **Web Framework**: Flask (REST API Support)
* **Vectorization**: TF-IDF Inference Logic
* **UI**: CSS3 / Bootstrap 5 / Font Awesome

## 📥 Installation
1. Clone the repository to your system.
2. Install dependencies: `pip install flask pandas scikit-learn`
3. Launch the service: `python web_app.py`
